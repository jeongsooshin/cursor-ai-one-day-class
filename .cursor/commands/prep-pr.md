# prep-pr — PR 전 점검

변경된 파일들을 PR 올리기 전 점검해줘.

## 절차

1. `npm test`를 실행하고 결과를 요약한다.
2. 테스트가 통과하면 변경 사항을 한국어 3줄로 요약한다.
3. Conventional Commits 형식(`feat:`, `fix:`, `chore:`, `refactor:`)으로
   커밋 메시지 제목 1줄 + 본문을 제안한다.
4. 마지막에 리뷰어가 특히 봐야 할 부분을 짚어준다.

## 보고 형식

| 섹션 | 내용 |
|------|------|
| 테스트 결과 | 통과/실패, 스위트·테스트 수, 소요 시간 |
| 변경 요약 | 한국어 3줄 |
| 커밋 메시지 | 제목 1줄 + 본문 |
| 리뷰 포인트 | 리뷰어가 집중할 항목 |

## 참고

- 테스트 실패 시: 실패 원인 요약 후 커밋 메시지·리뷰 포인트는 생략한다.
- PR에 포함할 파일 범위(무관한 untracked 파일 등)도 함께 짚어준다.
